# ☕ Beanora — Coffee Landing Page

A modern and responsive coffee shop landing page built using **HTML5 and CSS3**.

Beanora is a fictional coffee brand created as a frontend practice project to improve my skills in **HTML, CSS, responsive design, Flexbox, CSS Grid, forms, and modern web layouts**.

---

## 🌐 Live Demo

🔗 **Live Website:**  
[Beanora](https://kiruthika-m-2210.github.io/Beanora/)

## ✨ Features

- ☕ Modern coffee shop landing page
- 🎥 Full-screen video background in the hero section
- 📱 Responsive design for desktop, tablet, and mobile
- 🧭 Sticky navigation bar
- 🍵 Coffee menu section
- 🌿 About section
- 🎁 Special offers section
- ⭐ Customer reviews section
- 📩 Contact form
- 🔗 Social media links
- 🎨 Coffee-inspired color palette
- ✨ Google Fonts integration
